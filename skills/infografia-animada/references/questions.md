# Question script

Ask once, in a single round. Skip any question the user already answered in their request. Allow
multiple selections on the animation question.

## 1. Palette

"Which palette should this use? (background, ink, accent, cards, flow)"

- **Technical navy (recommended)**: background #0B1020, bands #132040 and #0D1529, cards #1A2A4A
  with border #2C4270, ink #EEF3FF and #A3B3D3, accent #FFB020, flow #3DD6E8. Poppins, Inter,
  JetBrains Mono.
- **Editorial paper**: background #F6F1E7, bands #EDE5D4 and #F6F1E7, cards #FFFFFF with border
  #D9CDB5, ink #1B1B1F and #5C5A55, accent #D3472E, flow #1F6F8B. Archivo Black, Inter,
  JetBrains Mono.
- **Neon graphite**: background #111214, bands #1A1B1F and #111214, cards #202227 with border
  #34373E, ink #F2F2F2 and #A8ABB3, accent #C8FF3D, flow #7C5CFF. Poppins, Inter, JetBrains Mono.
- Other: ask for hex values in the order background, ink, accent, cards, flow.

## 2. What animates (multiple choice)

"Which parts should animate? Everything enters with a staggered spring; pick the extras."

- Connector lines with continuous dotted flow (recommended)
- Backgrounds and bands enter too, rather than staying fixed
- Icons with a gentle continuous pulse
- Numerals with a counting or subtle rotation effect

## 3. Format

- 3:4 vertical 960x1280 (recommended for infographics)
- 9:16 vertical 1080x1920 (stories and reels)
- 1:1 1080x1080
- 16:9 1920x1080

## 4. Signature

"What signature should it carry, and where?" Options: a handle bottom-right (recommended), no
signature, or something else.

## After the answers

Repeat the chosen palette and format in a small table alongside the verification still from step 7
of the workflow, so the user validates both in one glance.
